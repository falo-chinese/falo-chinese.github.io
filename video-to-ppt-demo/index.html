📖 Video Slide Extractor 運作原理與影像處理教材

一、專案精神與核心理念 (KM Philosophy)

本專案的核心目標在於：「捕捉專家經驗，快速收納為知識管理 (KM) 資料庫」。

  • 高效知識沈澱：使用者不需花費數小時反覆觀看長篇教學影片，即可透過此程式快速抽離出演講、簡報或課堂的精華大綱。
  • 零執行成本 (No AI API Cost)：全部運算皆由本機高效電腦視覺演算法完成，執行時完全不消耗 any AI API Token，免去高昂的雲端依賴。
  • 人機協作控制 (Human-in-the-Loop)：程式演算法進行影格降噪，並將最終決定權交付給人類進行版本比對，保證 100% 精確性。

二、核心演算法工作流程 (Algorithm Workflow)

系統底層實作了 7 階段的電腦視覺演算法流水線（基於畫面變動監控）：

  1. 1. 影片分析：讀取解析度、FPS、時長並解析格式。
  2. 2. 畫面變化偵測：低解析快速計算影格 MAE 差值。
  3. 3. 換頁推測：在 MAE 變動曲線波峰處進入穩定度追蹤。
  4. 4. 相似度分析：計算 HSV 直方圖與結構相似度（SSIM）。
  5. 5. 模糊檢測：Laplacian 梯度變異數過濾淡入淡出及過渡。
  6. 6. 重複頁排除：利用 dHash 差異雜湊與平均色彩濾除重複。
  7. 7. 候選投影片：決定擷取投影片，並從原始最高解析度裁剪。

三、影像處理與強化技術說明

  • 文字邊緣銳化 (Unsharp Masking)：利用 Gaussian 模糊與原圖相減提取高頻邊緣並疊加，使模糊字體邊緣變清晰。
  • 對比度增強 (CLAHE)：自適應直方圖均衡化，在局部網格內增強文字與背景對比，適合複雜色彩簡報。
  • 邊緣保留去噪 (Bilateral Filter)：雙邊權重濾波，在平滑壓縮馬賽克雜訊時保護文字邊緣不發糊。
  • 文檔講義化模式 (Scan Mode)：自適應二值化，文字純黑背景純白，節省 90% 空間且有掃描講義質感。
  • 智慧放大 (Super Resolution 2x/4x)：整合 Lanczos-4 插值與 USM 邊緣重建，實現高畫質字元邊緣放大。
